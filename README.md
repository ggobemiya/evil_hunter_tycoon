## GitHub Pages 업데이트 요약

이 프로젝트를 GitHub Pages (ggobemiya.github.io/evil_hunter_tycoon/)에 업데이트하려면 다음 단계를 따르세요. 자세한 내용은 `GEMINI.md`를 참조하십시오.

1.  **프로젝트 빌드**: 최신 변경사항을 반영하기 위해 프로젝트를 빌드합니다.
    ```bash
    npm run build
    ```
2.  **변경사항 커밋**: 빌드된 파일과 소스 코드 변경사항을 Git 저장소에 커밋합니다.
    ```bash
    git add -A
    git commit -m "feat: <변경 내용 요약>"
    ```
3.  **GitHub에 푸시**: 커밋된 변경사항을 원격 GitHub 저장소에 푸시합니다.
    ```bash
    git push
    ```
## 정보 탭 및 유물 계산기 (2026-11-17)

- 성격: 헌터 성격 33종과 효과.

- 일반/영웅 월드보스 티어는 각각 숫자 입력과 1~5티어 슬라이더로 조절합니다.
- 월드보스·필드보스·탐험 횟수는 초기 0입니다. 유적 발굴은 2시간당 1회분으로 하루 24시간분(주 84개), 챌린저스 샵 주 2회, 승리의 메달 샵 14일 시즌당 2회를 기본값으로 적용합니다. 발굴 수령 시간분은 누락 시간을 반영해 조정할 수 있습니다.
- 유물 만렙은 종류당 271개(최초 활성화 1개 포함), 30종 총 8,130개입니다.
- 랜덤 상자는 5개 50토큰 / 25개 250토큰, 선택 상자는 1개 50토큰입니다(사용자 제공 게임 화면).
- 랜덤 기간은 1/30 균등 추첨 256회 모의실험의 평균과 중간 80% 범위입니다. 초과 유물은 즉시 5토큰으로 교환합니다. 평균 수급량으로 일수를 환산하므로 보상 일정, 실제 획득 운, 묶음 구매 잔여 상자에 따른 오차가 있습니다.
- 선택 상자는 부족한 유물만 선택합니다. 현재 누적 획득량에는 레벨업에 소비한 수량도 포함합니다.
- 정보 출처: 공식 카페 게시글 51803(담금질), 51391(수급), 51395(유물), 16163(성격).

### 유물 입력 자동 저장
입력값·현재 토큰·유물 보유량은 `eht.relicPlanner.v1` 키로 이 브라우저에 자동 저장됩니다. 최초에는 월보 각각 4티어 주 3회, 필보 하루 3회, 탐험 하루 2회(당첨 35개 가정), 발굴 하루 24시간, 상점 최대 구매 및 제공된 Lv.3~5 보유량 예시가 적용됩니다. 저장값이 있으면 우선 복원합니다. 탐험 35개는 미확인 가정이므로 게임 보상 확인 후 수정해야 합니다. 보유량은 레벨과 다음 레벨을 위해 모은 개수로 입력합니다.
